# 🗺 План отладки, тестирования и развёртывания (Roadmap)
Покерная система таймеров для ТВ и дилеров — Антикафе «Атмосфера»

---

## 📌 Шаг 1. Локальная отладка и предпросмотр (Прямо сейчас)

Фронтенд спроектирован так, что он полностью функционален локально без внешних серверов (синхронизируется через `storage` события браузера):

1. **Запуск локального сервера:**
   В корне проекта `c:\vibe\` запустить локальный сервер:
   ```bash
   npx serve .
   ```
2. **Проверка взаимодействия:**
   * Открыть в одном окне браузера: `http://localhost:3000/tv/index.html` (симуляция ТВ).
   * Открыть во втором окне (в режиме мобильного экрана): `http://localhost:3000/dealer/index.html` (симуляция дилера).
   * Нажать **«Старт игры»** в пульте дилера $\rightarrow$ на ТВ мгновенно стартует таймер стола конкретного ведущего.
   * Нажать **«Пауза»** $\rightarrow$ проверить остановку времени на ТВ.
   * Нажать **«Завершить игру»** $\rightarrow$ проверить запуск 10-минутного отсчёта на ТВ и открытие предзаполненной Google Form.

## 📌 Шаг 2. Создание бесплатного проекта Firebase (Realtime-шина)

1. Зайти в [console.firebase.google.com](https://console.firebase.google.com/) под своим Google-аккаунтом.
2. Нажать **«Создать проект»** $\rightarrow$ назвать `atmosphere-poker` (Google Analytics можно отключить).
3. В левом меню перейти в **Build $\rightarrow$ Realtime Database** $\rightarrow$ нажать **«Создать базу данных»**.
4. Выбрать локацию (например, `europe-west1` / `Бельгия` или `us-central1`).
5. Во вкладке **Rules (Правила)** разрешить чтение и запись для приложения:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
6. В настройках проекта (**Project Settings $\rightarrow$ General**) добавить Web App и скопировать `firebaseConfig` в `tv/tv.js` и `dealer/dealer.js`.

## 📌 Шаг 3. Деплой фронтенда на Cloudflare Pages (или GitHub Pages)

1. Зайти на [dash.cloudflare.com](https://dash.cloudflare.com/) $\rightarrow$ раздел **Workers & Pages**.
2. Нажать **Create application $\rightarrow$ Pages $\rightarrow$ Connect to Git** (выбрать репозиторий `leaderboard-mini-apps`).
3. Настройки сборки:
   * **Framework preset:** `None` (чистый HTML/JS).
   * **Build output directory:** `.` (корень).
4. Нажать **Save and Deploy**.
5. Через 30 секунд у вас будет постоянный бесплатный HTTPS-адрес:
   * ТВ-экран: `https://atmosphere-poker.pages.dev/tv/index.html`
   * Пульт дилера: `https://atmosphere-poker.pages.dev/dealer/index.html`

## 📌 Шаг 4. Регистрация `@atmosphere_dealer_bot` в BotFather

1. Открыть Telegram и написать официальному боту [@BotFather](https://t.me/BotFather).
2. Отправить команду `/newbot`.
3. Ввести имя: `Атмосфера • Дилеры`.
4. Ввести юзернейм: `atmosphere_dealer_bot` (или `atmosphere_staff_bot`).
5. Скопировать полученный `API TOKEN`.
6. Настроить кнопку Mini App для дилеров:
   * Отправить команду `/newapp` $\rightarrow$ выбрать созданного бота.
   * Название: `Пульт Ведущего`.
   * Описание: `Управление покерным столом и блайндами`.
   * Ссылка на Web App: `https://atmosphere-poker.pages.dev/dealer/index.html`.
   * Short name: `control`.
   * Получится ссылка: `https://t.me/atmosphere_dealer_bot/control`.
7. Добавить меню-кнопку (Menu Button):
   * Отправить `/setmenubutton` $\rightarrow$ выбрать бота $\rightarrow$ указать URL `https://atmosphere-poker.pages.dev/dealer/index.html` $\rightarrow$ текст кнопки: `🎛 Пульт ведущего`.

## 📌 Шаг 5. Полевое тестирование на ТВ Samsung 75" в «Атмосфере»

1. **Запуск экрана:**
   * Включить телевизор Samsung UE75TU7100UXRU.
   * Открыть встроенный браузер (Samsung Internet).
   * Ввести URL: `https://atmosphere-poker.pages.dev/tv/index.html`.
   * Нажать на пульте ТВ `Enter` / дважды кликнуть по шапке для перехода в Fullscreen.
2. **Проверка фоновой музыки:**
   * Запустить приложение Яндекс Музыка на телевизоре $\rightarrow$ включить трек на колонку JBL.
   * Переключиться в браузер на ТВ с открытым таймером.
   * Убедиться, что музыка продолжает играть в фоне без прерываний и заиканий.
3. **Стресс-тест 4 столов:**
   * С четырёх смартфонов дилеров запустить 4 стола одновременно.
   * Проверить, что 75" 4K экран плавно перестраивается в сетку 2x2, все 4 стола чётко видны, а при остатке $\le 45$ сек плашка ведущего подсвечивается янтарным цветом.
