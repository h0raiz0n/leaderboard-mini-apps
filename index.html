Правила и очки

Как начисляются очки и достижения

Базовые очки за места

За каждое призовое место начисляются очки по формату игры:

Формат12345
SNG1063——
MTT30201495
MYSTERY1063——

Нокауты

Только в Mystery Bounty: за каждое выбивание — +20 очков. Нокауты не считаются ITM.

ITM — попадание в призы

  • SNG — места 1–3
  • MTT — места 1–5
  • MYSTERY — места 1–3 (нокауты не в счёт)

ITM нужен для рангов, стека и сравнения при равных очках.

Достижения — только за текущий месяц

🏷Ранг

Начисляется за число ITM за месяц:

РангITMОчки
🐟 FISH0–50
🦈 SHARK6–11+15
💪 LEGEND12–17+35
👑 BOSS18++50
💎Stack

Лесенка ITM: пороги 3, 7, 12, 18, 25… Каждый достигнутый уровень — +5 очков.

♠Set

Полный комплект (1-е + 2-е + 3-е место) за месяц — +10 очков за каждый комплект.

⚡Double

Две победы (1-е место) у одного ведущего за один день — +10 очков за каждую пару.

Итого за месяц = места + нокауты + Ранг + Stack + Set + Double.

За всё время

Считаются только очки за места и нокауты — без месячных достижений.

Сортировка и тренд

  • Рейтинг сортируется по очкам; при равенстве выше тот, у кого больше ITM.
  • Тренд 🔼 / 🔽 — изменение места относительно последнего игрового дня (снапшоты в ср, пт, сб). 🆕 — новый в рейтинге месяца.

Подиум и MTT

Вкладка «Подиум» — призовые места 1–5 в MTT. В карточке игрока есть «MTT-подиум» — все места 1–5 в MTT за всё время.
