# 🚀 ATMOSPHERE POKER ENGINE 2.0: UNIVERSAL PROMPT RUNNER
> **Файл универсального промпта для итеративного прогона Antigravity от текущего состояния до 9.5 / 10.**

Этот документ содержит **один универсальный промпт**, который можно подавать в Antigravity снова и снова (пошагово или через команду `/goal`). Каждый вызов промпта берет ровно **одну очередную задачу** из [`ROADMAP.md`](file:///c:/vibe/ROADMAP.md), доводит её до идеала, тестирует, бампает кэш, деплоит на Vercel через Git push и переключает чек-лист на следующую задачу.

## 📋 Как использовать этот файл

### Вариант 1: Пошаговый контролируемый прогон (Рекомендуется для максимального контроля)
1. Скопируй текст из блока **«Универсальный промпт для копирования»** ниже.
2. Отправь его в чат Antigravity.
3. Antigravity прочитает [`ROADMAP.md`](file:///c:/vibe/ROADMAP.md), выполнит текущую задачу (например, `1.1 [FIX]`), проверит линтером Impeccable, прогонит все тесты, сделает коммит и пуш на Vercel, обновит `ROADMAP.md` и отчитается.
4. Повтори отправку того же самого промпта для следующей задачи (`1.2 [VERIFY]`) и так далее до задачи `5.2`.

### Вариант 2: Автономный запуск в фоне через `/goal`
1. Напиши перед промптом префикс `/goal`.
2. Вставь универсальный промпт.
3. Antigravity будет самостоятельно циклически выполнять шаги один за другим, пока все 10 задач не получат статус `[DONE]`.

     * Напиши или обнови специализированный Playwright E2E тест в tests/ (например, tests/test_e2e_split_screen_dual_pillars.js).

     node tests/run_all_tests.js

   - Добавь актуальную версию кэша в tests/test_performance_and_caching.js и проверь его.
   - Выполни git status, сделай git add -A, осмысленный коммит и git push origin main.
   - Убедись, что рабочее дерево git чистое (working tree clean).

5. ОБНОВЛЕНИЕ ЧЕК-ЛИСТА В ROADMAP.MD:
   - В c:\vibe\ROADMAP.md отметь выполненную задачу как [DONE] с указанием версии и хэша коммита.
   - Переведи следующую задачу по списку в статус [IN_PROGRESS].

6. ОТЧЕТ ПОЛЬЗОВАТЕЛЮ:
