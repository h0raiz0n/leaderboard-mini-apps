# 📋 План спринта 2: Чистый бот, реестр дилеров, гибкие перерывы и Impeccable ТВ-таймер

Спринт составлен на основе замечаний пользователя. Каждый шаг завершается автоматическим тестом, Git-коммитом, пушем в GitHub и деплоем в Google Apps Script. В точке **Фаза 4** работа приостанавливается для ввода списка дилеров от пользователя.

## 🏗 Фаза 1. Чистый бот и единый реестр дилеров

### [x] Шаг 1.1. Аудит триггеров и гарантированная тишина бота
* **Что делаем:**

## 🎨 Фаза 3. Impeccable Редизайн ТВ-таймера (4K Broadcast HUD)

### [ ] Шаг 3.1. Типографика, акцент на текущие блайнды и явное АНТЕ
* **Что делаем:**
  * Повышаем контраст и размер текущих блайндов (`56-64px`, `800-900`, `tabular-nums`).
  * Добавляем явную контрастную плашку **«АНТЕ: ХХХ»** / **«BBA ХХХ»**.
  * Приглушаем следующий раунд (`20-22px`, 50% opacity), фокусируя внимание на текущем уровне.
* **Тест:** `tests/test_tv_4k_stress.js`
* **Деплой:** Git commit $\rightarrow$ Push to GitHub.

### [ ] Шаг 3.2. Алерт за 30 секунд и статус финального раунда с овертаймом
* **Что делаем:**
  * Смена янтарного алерта переводится с 45 на **30 секунд** (`remaining <= 30`).
  * На финальном уровне после `00:00` включается статус **«ФИНАЛЬНЫЙ РАУНД • БЛАЙНДЫ ЗАФИКСИРОВАНЫ»** со счетчиком овертайма (`+00:01`, `+01:30`).
* **Тест:** `tests/test_timer_overtime_and_alerts.js`
* **Деплой:** Git commit $\rightarrow$ Push to GitHub.
