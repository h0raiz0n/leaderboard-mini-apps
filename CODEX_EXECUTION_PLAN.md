# 🚀 ИНСТРУКЦИЯ И ЦИКЛИЧЕСКИЙ ПРОМПТ ДЛЯ ANTIGRAVITY
Покерная экосистема «Атмосфера»

---

## 1. Как устроен процесс

1. Весь мастер-план и актуальный статус задач зафиксированы в **`ORCHESTRATOR.md`**.
2. Каждая задача разбита на пары:
   * `[ ] TASK-...` — реализация функционала или устранение бага.
   * `[ ] VERIFY-...` — независимый автотест (unit / E2E / regression) + сборка и деплой.
3. Вы просто отправляете один и тот же промпт (приведен ниже) в диалог с Antigravity.
4. Модель сама:
   * Находит очередную незакрытую задачу.
   * Аккуратно её решает, не ломая соседние узлы.
   * Запускает E2E-тест и подтверждает работоспособность.
   * Фиксирует `[x]` в `ORCHESTRATOR.md`.
   * Делает коммит, пуш и деплой.

---

## 2. 📋 ЦИКЛИЧЕСКИЙ ПРОМПТ ДЛЯ ВСТАВКИ В ЧАТ

Скопируйте и отправьте следующий текст в диалог с Antigravity:

```text
/goal Ты работаешь по протоколу ORCHESTRATOR.md для покерной системы «Атмосфера». Твоя цель — довести проект до планки качества 9.5 из 10.

Твой алгоритм действий на эту итерацию:
1. Изучи ORCHESTRATOR.md и найди первую незакрытую задачу [ ] TASK-... (или парную [ ] VERIFY-...).
2. Реализуй задачу с максимальным качеством (чистый, надежный код, устранение медлительности, синхронизация фронтенда и бэкенда, удаление мертвого кода).
3. Запусти тесты (консольные, Playwright/E2E эмуляция или браузер) и убедись, что функционал работает идеально и без регрессий.
4. Выполни сборку/деплой (в Google Apps Script через deploy_apps_script.js и/или git push в Vercel).
5. Отметь выполненную задачу в ORCHESTRATOR.md как [x].
6. Выведи краткий, емкий отчет пользователю о том, что сделано, какой автотест подтвердил результат и какая задача будет следующей.
```

---

## 3. Советы по контролю качества

* Вы можете запустить этот промпт через `/goal`, чтобы агент самостоятельно прошел несколько шагов подряд до завершения спринта.
* В любой момент вы можете открыть `ORCHESTRATOR.md` в редакторе и увидеть точный процент готовности системы.
