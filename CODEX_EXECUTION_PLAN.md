## 📌 Универсальный многоразовый промпт для запуска

Вы можете скопировать и отправлять этот промпт снова и снова (или запустить с командой `/goal` для непрерывного выполнения):

```markdown
/goal Ты работаешь по протоколу ORCHESTRATOR.md для покерной системы «Атмосфера». Твоя цель — довести проект до планки качества 9.5 из 10.

Твой алгоритм действий на эту итерацию:
1. Изучи ORCHESTRATOR.md и найди первую незакрытую задачу [ ] TASK-... (или парную [ ] VERIFY-...).
2. Реализуй задачу с максимальным качеством (чистый, надежный код, устранение медлительности, синхронизация фронтенда и бэкенда, удаление мертвого кода).
3. Запусти тесты (консольные, Playwright/E2E эмуляция или браузер) и убедись, что функционал работает идеально и без регрессий.
4. Выполни сборку/деплой (в Google Apps Script через deploy_apps_script.js и git push в main на GitHub Pages).
5. Отметь выполненную задачу в ORCHESTRATOR.md как [x].
6. Сделай коммит в git с понятным описанием изменений.
7. Переходи к следующей задаче, пока все задачи в ORCHESTRATOR.md не будут закрыты [x].
```

## 📋 Что покрывает план:
1. **Безопасность:** Полная изоляция токенов и очистка клиентского кода от секретов.
2. **Тишина бота:** Гарантированная ликвидация 5-минутных пушей (`drop_pending_updates`, фильтрация старых апдейтов, удаление лишних триггеров).
3. **Автоопределение ведущего:** Автоматическая привязка к Telegram `initDataUnsafe` без ручных кнопок выбора.
4. **Структуры блайндов:** Удаление колор-апа и 5-минуток $\rightarrow$ 2 чистые 7-минутные структуры (стандартная с анте и классика без анте).
5. **МТТ-модуль:** Ввод участников, кнопка «Аут», умный ребаланс столов с рандомайзером боксов (1..10) и рероллом, ТВ-виджет среднего стека.
6. **Чистка кода и E2E тесты:** Удаление мертвого кода, регрессионный сьют из 12+ тестов и боевой деплой.
