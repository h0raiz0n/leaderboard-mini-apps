Покерная экосистема клуба «Атмосфера»

## 1. Контекст проекта: Зачем всё существует и как работает

Покерная экосистема антикафе «Атмосфера» объединяет 4 ключевых компонента, работающих в режиме реального времени:

1. **4K TV Dashboard (`/tv/`):**
   * **Назначение:** Отображение на 75-дюймовом телевизоре таймеров, текущих/следующих блайндов, анте, перерывов и турнирной статистики (до 4 столов одновременно).
   * **Особенности:** Должен быть идеально читаем с 5–10 метров в 4K разрешении, иметь звуковые алерты (за 30 секунд до конца раунда) и нулевой дрифт времени. В режиме МТТ показывает суммарное количество игроков, средний стек турнира и бегущую строку ребаланса столов.

2. **Пульт ведущего — Telegram Mini App (`/dealer/`):**
   * **Назначение:** Быстрое управление таймером стола (старт, пауза, таймированный перерыв 2-5-10 мин, ауты игроков, ребаланс боксов).
   * **Особенности:** Сверхбыстрый отклик (<20мс), тактильная виброотдача, автоматическое определение имени ведущего по Telegram `initDataUnsafe`. При прямом открытии через браузер защищен Master PIN-кодом.

3. **Telegram-бот авторизации (`@atmosphere_poker_dealer_bot`):**
   * **Назначение:** Проверка белого списка 12 ведущих клуба и выдача кнопки открытия пульта.
   * **Особенности:** 100% тишина (ноль спам-пушей, мгновенный сброс очереди ретраев Telegram `drop_pending_updates: true`, реакция строго на свежие `/start`).

4. **Лидерборд и база результатов (`/` и Google Таблицы):**
   * **Назначение:** Регистрация результатов турниров, автоматический подсчет рейтинговых очков сезона, Зал славы, динамический реестр ведущих на отдельном листе.
   * **Шина данных:** Firebase Realtime Database для передачи состояний столов ведущих на ТВ-экраны за 20мс.

## 2. Архитектурный протокол: `ORCHESTRATOR.md`

Все задачи в проекте строго разбиты на пары:
* `[ ] TASK-...` — Высококачественная реализация (чистый код, оптимизация, согласованность UI и бэкенда).
* `[ ] VERIFY-...` — Сквозной E2E автотест (проверка логики, отсутствие регрессий, Git commit, push и деплой в Apps Script / Vercel).

## 3. Универсальный повторяемый промпт для запуска

Вы можете скопировать этот блок и отправлять его модели снова и снова. Модель автоматически находит следующую незакрытую задачу, реализует её, тестирует, коммитит и переходит дальше:

```markdown
/goal Ты работаешь по генеральному протоколу ORCHESTRATOR.md для покерной системы «Атмосфера». Твоя цель — довести систему до планки качества 9.5 из 10.

Твой алгоритм действий на эту итерацию:
1. Открой и изучи ORCHESTRATOR.md, найди первую незакрытую задачу [ ] TASK-... (или парную [ ] VERIFY-...).
2. Изучи контекст и файлы, относящиеся к этой задаче.
3. Реализуй задачу с максимальным качеством:
   - Полная согласованность фронтенда, бэкенда и базы данных.
   - Защита от несанкционированного доступа.
   - Чистый, производительный код без лишних сетевых вызовов.
   - Удаление мертвого и неиспользуемого кода.
4. Запусти соответствующий автотест из каталога tests/ (или создай его) и добейся 100% прохождения.
5. Выполни проверку полного набора тестов: node tests/run_all_tests.js.
6. Выполни деплой (в Google Apps Script через deploy_apps_script.js и git push origin main для Vercel/GitHub).
7. Отметь выполненную задачу в ORCHESTRATOR.md как [x].
8. Сделай понятный git-коммит и push в репозиторий.
9. Продолжай движение по чеклисту, пока все фазы в ORCHESTRATOR.md не будут закрыты [x].
```
